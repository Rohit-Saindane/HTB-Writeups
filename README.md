# Hack The Box (HTB) Writeups Repository
**Saindane Rohit** | B.Tech in Computer Science & Engineering with Specialization in CyberSecurity

Welcome to my repository of Hack The Box (HTB) lab writeups. This project serves as a technical diary of my journey in penetration testing and security research.

---

### 📌 About This Repository:
As a Cybersecurity student, I use these labs to apply theoretical knowledge to practical scenarios. My writeups focus on:
- **Detailed Enumeration**: Mapping attack surfaces systematically.
- **Exploitation Methodology**: Understanding the "why" behind the vulnerability.
- **Post-Exploitation**: Privilege escalation, Active Directory exploitation, and lateral movement.
